# AI Smart Trip Planner (TripWise)

A Flask + SQLite travel planner with AI itinerary generation, map-search links, live weather lookup (Open-Meteo), saved trips and PDF export.

## 1. Requirements
- Python 3.10 or newer
- Internet connection
- An OpenAI API key with API billing/credits enabled

## 2. Setup (Windows PowerShell)
Open this project folder in VS Code terminal and run:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

If PowerShell blocks activation, use Command Prompt:
```bat
venv\Scripts\activate.bat
```

## 3. Configure AI
Copy `.env.example` to a new file named `.env`. Add your own API key:
```
OPENAI_API_KEY=your_actual_key
OPENAI_MODEL=gpt-4.1-mini
FLASK_SECRET_KEY=any_long_random_secret
```
Never upload `.env` or share your API key publicly. API usage may incur charges.

## 4. Run
```powershell
python app.py
```
Open http://127.0.0.1:5000 in your browser. Stop the server with Ctrl+C.

## Features
- Validated trip form and AI-generated day-wise itinerary
- SQLite saved trips (local device)
- PDF itinerary export
- OpenStreetMap search links
- Current weather snapshot using Open-Meteo (internet required)

## Important limitations
- AI suggestions are not verified reservations, live hotel availability, confirmed prices, or guaranteed opening hours.
- Hotel/restaurant names generated by AI must be independently checked before booking.
- Weather snapshot is current/near-term weather, not a date-specific forecast for far-future travel.
- This starter has no user accounts. Anyone with access to the local app can view its saved trips.
- Before public deployment, set `debug=False`, use a strong secret, add authentication/CSRF protection, rate limits, logging, and production hosting.
